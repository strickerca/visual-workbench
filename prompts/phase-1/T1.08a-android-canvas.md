## Goal

The phone app's foundation: precise, fast pen input on a canvas that works with no PC.

## Steps

1. Structure: a Compose single-activity app with these screens:
   - Projects; Canvas; Settings;
   - Diagnostics (move the T0.04 trace recorder here);
   - Pairing (a placeholder labelled "available after T1.10" — never an inert control).
2. Stylus abstraction (PEN-015): read MotionEvents, including historical samples, tool type, pressure, tilt/orientation if present, hover, buttons and cancel flags. Produce normalized samples plus capability flags. Samsung-only features sit behind an interface whose default does nothing. A generic stylus profile (Samsung module disabled) must run the app fully on standard MotionEvent data.
3. Canvas:
   - images up to 50 MP decoded in memory, using the core's RAM cache budget, opened for now through a temporary "Open image" button using the system photo picker (the full import paths come in T1.11); images over 50 MP are refused with "Images over 50 megapixels aren't supported yet" — never downsampled;
   - annotations from core render lists;
   - camera through vw-geom;
   - gestures per §4.16: pen = tool; one-finger pan; two-finger pinch/rotate with 0/90/180/270 snapping; two-finger tap = undo; three-finger tap = redo; long-press = context menu.
4. Wet ink: a front-buffered renderer with motion prediction, drawing the core's incremental geometry. Dry ink commits at pen-up. Palm touches and cancelled pointers send a cancel and commit nothing.
5. Tools in this task: pen, highlighter, marker; undo/redo. Settings → "Draw with finger" (off by default; PEN-003).
6. Offline: local projects through vw-store; the app works fully in airplane mode (the phone part of SYNC-001).
7. Measure PERF-001 with the T0.04 method. Add instrumentation tests that inject events for the gesture map, for palm/cancel, and for the generic stylus profile; run them through `hil-test`.
