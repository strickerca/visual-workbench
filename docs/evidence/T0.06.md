## Real S23 adb measurement

SM-S918U (Samsung Galaxy S23 Ultra), Android 16/API 36, native arm64 client;
Windows release server on loopback, plain TCP through an owned adb reverse
mapping. This diagnostic transfers synthetic bytes only. Production TCP still
requires TLS and the product multiplexer. adb reverse supports TCP/local sockets,
not UDP, so it cannot carry QUIC datagrams.

The full profile measured 1,000 echoes at each size after ten excluded warmups.
Nearest-rank percentiles and mean absolute successive RTT differences are used.
Payload checking occurs outside the echo timer. All 3,000 measured echoes were
byte-verified. Bulk measures client-to-server transfer including receiver checking
and the final acknowledgment, not a nominal USB link rate.

| Echo payload | p50 RTT (ms) | p95 RTT (ms) | p99 RTT (ms) | Mean successive delta (ms) |
|---|---:|---:|---:|---:|
| 64 B | 9.703 | 40.273 | 64.194 | 8.967 |
| 4 KiB | 8.016 | 32.896 | 74.416 | 7.429 |
| 1 MiB | 70.394 | 133.265 | 222.764 | 19.319 |

Verified 256 MiB bulk throughput: **32.41 MiB/s**. This single run is sensitive to
machine load and is not a sustained product performance guarantee. RTT is not
one-way latency, phone stroke-to-PC presentation, or a clock-offset estimate.
