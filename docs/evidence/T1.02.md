## Implementation

`vw-model` supplies versioned projects, image/PDF/SVG/capture documents, immutable
asset metadata, layers, all 13 object variants, acyclic groups, instructions,
semantic snapshots, result candidates and nondestructive mask-operation history.
Timeline and unknown document/schema versions return typed errors. Capture
session/frame/geometry values round-trip exactly; semantic snapshots must match
their capture binding. Captured text remains explicitly untrusted. Result metadata
checks are model-level minimums; image proof computation belongs to later tasks.

IDs are canonical UUIDv7, Crockford base32 device IDs and BLAKE3 asset IDs.
Canonical JSON sorts maps, normalizes signed zero, rejects nonfinite geometry,
and preserves exact f64 reload values. A schema/domain prefix separates state
hashes from asset hashes. State hashes exclude views, sequence counters, history,
provisional gestures and conflicts. Original blob bytes are outside this crate.
Fractional ordering uses validated base62 keys with stable entity-ID tie breaks;
exhausted 128-digit intervals return an explicit rebalance-required error.

`vw-proto` generates draft Rust types with prost and vendored protoc. Only two
additive wire changes were needed: Op field 28 (`UndoTransaction`, referencing
an accepted transaction ID) and TxnAck field 4 (property-only notices). The host
derives inverses from its validated journal; clients cannot supply arbitrary
restoration patches. The largest Envelope gesture variant is boxed in Rust
without changing protobuf bytes or field numbers. T1.06a finalizes the protocol.

`vw-ops` validates authenticated identities, known base hashes, Lamport IDs,
ownership, references, locks and cycles before atomically installing a candidate.
Exact transaction retries return the original acknowledgement without replaying
effects or conflicts; reused IDs with changed bytes fail. Live writes follow host
order. Stale writes use wall-clock ordering with ties favoring the host; explicit
equal-value writes preserve ownership without redundant conflict records.
Ownership is resolved per effective leaf so sibling writes cannot hide a peer
edit during deletion or whole-shape replacement. Delete beats edit and retains
the edited object, including late reorder/property edits to a tombstone.

Replicas apply ordinary and inverse transactions optimistically, retain pending
work through rebase, and expose blocked entries instead of silently dropping
them. Inverses include locally queued offline work. Undo history belongs to one
device/project and follows host sequence, not acknowledgement arrival order.
Lost, repeated and reordered receipts reconcile through a byte-bound journal.
Undo skips later peer-written properties and preserves dependent parent state
with notices. Explicit pending rejection removes its causal inverse chain while
preserving unrelated queued work. Redo targets the actual inverse transaction.

Provisional gestures expire at exactly 1,000 ms. Cancel/commit removes previews
immediately; retained sequence watermarks prevent stale packets reviving expired
ink. Host gesture identities reject cancelled or repeated commits. Rendering
replacement within a frame and the 120 Hz sender remain app/transport work.
