## Goal

The protocol, the session layer and both carriers, plus a deterministic simulator that proves sync never loses or duplicates edits.

## Steps

1. Finalize `contracts/vw_protocol.proto`, with a changelog comment block at the top, and regenerate `vw-proto`. Keep the pairing messages (PairingProof, PakeMessage, PairingResult) as drafted; T1.06b implements them.
2. `core/crates/vw-net`, session layer:
   - Transport-agnostic, with channels CONTROL / OPS / EPHEMERAL / BLOB / MEDIA / INPUT and the semantics of §4.6.
   - Reconnection: OPS resync via SyncRequest/SyncBatch; EPHEMERAL cleared; INPUT session invalidated.
   - The connection state machine of §4.18, exposed as events the apps turn into status words.
3. Carriers:
   - QUIC: quinn with the `rustls-ring` feature and rustls's `ring` provider (not the default aws-lc-rs), using streams and datagrams.
   - TCP-mux for adb: length-prefixed frames; latest-only keys for EPHEMERAL and MEDIA; TLS 1.3 inside the tunnel.
   - Test certificates for now; T1.06b adds real device identity and pinning.
   - Carrier order per the dated D7 entry.
4. `core/crates/vw-sim`: a deterministic simulation of host and phone replicas (from vw-ops) over a simulated network with seeded faults (drop, duplicate, reorder, delay, partition, offline periods). After quiescence:
   - state hashes are equal;
   - no transaction is lost or duplicated;
   - no INPUT event is ever replayed;
   - a duplicated transaction is acknowledged without being applied twice (SYNC-004).
   Run 10,000 seeds in under 10 minutes; failing seeds must reproduce exactly.
5. MEDIA on hardware (CONNECT-004): a synthetic frame source at twice what the link can carry; on both carriers the receiver must only ever render the newest frame per key.
6. Windows Firewall: explain to Christian, then (with his approval of the admin prompt) add temporary inbound allow rules for the executable under test, limited to the local subnet, for example `New-NetFirewallRule -DisplayName "VW dev <task>" -Direction Inbound -Action Allow -Program <full path to the exe> -Protocol UDP -RemoteAddress LocalSubnet -Profile Any` and the same for TCP. If Windows already created a Block rule for that executable, delete it. Never conclude that a carrier fails until a firewall block has been ruled out. Remove the rules at the end of the task.
7. Hardware smoke: exchange ops between the PC and an adb-pushed phone binary over tethering and over adb.
