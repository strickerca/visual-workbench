## Implementation

`vw-geom` now provides validated f64 points, rectangles, affines, inverse and
composition, device-local cameras, rotated screens and insets, natural Android
display mapping, all eight EXIF orientations, PDF crop/rotation, centered SVG
meet/slice and stretch, pixel snapping, and precision-lens latching. Public
Rustdoc states coordinate conventions. Transcendentals/snapping use libm with
architecture-specific defaults disabled; library code has no unsafe blocks,
unwrap/expect/panic calls, or f32 coordinate conversions.

Capture mappings use integer pixel indices, negative host origins, exact quarter
turns, and checked geometry revisions. DPI is retained as metadata and never
multiplies coordinates that are already physical pixels. Continuous edge
transforms use width/height; integer pixel rotations use width−1/height−1.
Inverse row normalization handles opposing extreme axis scales. Invalid,
nonfinite, singular, stale and out-of-range inputs return typed errors.

The lens stores an exact base view and caches the inverse at pen-down. Toggles
queue until pen-up/cancel; the last request wins. Rejected transforms do not
alter queued state, and closing restores the saved base coefficients exactly.
