# Owner pen traces

This directory is reserved for reviewed S23 Ultra owner recordings. It currently
contains no hardware traces. Synthetic test data is generated inside ReplayTest
and is never counted toward the 24-trace acceptance check.

Follow tools/pen-trace/README.md. Use only test shapes and the word "ink"; traces
preserve handwriting and must be inspected before publication to this public
repository. Pull app-private traces to fixtures-private/ first, validate them,
then copy only the reviewed files here. Never put screenshots in this directory.
