## Goal

The rest of the phone's markup toolset and its final layout, with text that matches exports exactly.

## Steps

1. Tools: line, arrow, rectangle, ellipse, text, object eraser, select/move/resize with handles; color and width quick controls reachable from the pen (UX-004's pen quick controls).
2. Text: laid out and outlined by the core (vw-raster's layout through vw-ffi) and drawn as paths — never with Android or Compose text — so the phone matches exports. Add a golden comparing phone-rendered text at 1:1 with the export.
3. Brush settings (PEN-002): a monotonic 4-point Bézier pressure-curve editor with live preview, stored per brush; a stabilization slider 0–1; a hover cursor showing the stroke width when the device reports hover.
4. Layout per §4.17: tool rail on the left with a left-handed mirror, and movable (UX-002); status bar; context bar; dark and light themes; reduced motion honored; every touch target ≥ 48 dp (audit and record).
5. Contrast: check text and controls in both themes against WCAG 2.1 AA and record the ratios (UX-003).
6. Tests: instrumentation tests for each tool; replayed fixtures show the curve editor and stabilization changing the output.
