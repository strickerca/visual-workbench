## Implemented boundary

two-input permit/4 MiB charge, opens the non-following regular File and creates a
new private TempDir before immediately attaching their existing picked owner.
Opening is synchronous with no new worker/thread; the shared caller executes it
off UI in the existing joined independent stream task. A content URI is refused.
Preparation transfers that admission once, without another pool or whole-original
byte vector. Closing the consumed picker cannot seal the independent prepared
owner. Returned metadata contains dimensions/orientation/format/size/hashes only.

PreparedOriginal exposes its approved build, GiantBuiltCache exposes publication
and close, and ProjectSession exposes exact-bound rebuild. The compiled platform
selects the fixed Android JPEG or already-packaged pinned Windows producer. No
foreign platform/runtime/path approval switch, completed-directory factory or
production fake-build constructor exists. Linux production builds remain
Unsupported. PNG header preparation does not imply Android PNG producer support.

Publication adopts all four accepted store/blobs/SessionPermit/charge fields into
the budgeted ProjectSession. Accepted destinations survive failed/cancelled
foreign delivery. Shared rebuild borrows the actual NativeProject under its
close mutex until joined native work settles, avoiding a disposed foreign handle
race. Stale bindings still refuse in the existing native/project worker.

WorkbenchCore gains an optional WorkbenchGiantImportCore capability; existing
interfaces/fakes require no new mandatory methods. Shared opaque wrappers serialize
calls and close, use existing cancellation/error mapping and retain exact failed
native owners globally for retry. Destruction follows successful native retirement;
a failed destroy retries without repeating successful retirement. Undelivered or
failed facade construction follows the same rule. New project facades preserve
the existing NativeProject capabilities with this strict owner, seal calls on
attempted close and always retry the exact failed owner instead of returning a
no-op success. Ordinary project close behavior is otherwise unchanged.

Retry observes the native owner's actual retirement result. The admitted native
storage quarantine intentionally retains uncertain directories for process life;
this facade does not automatically delete/retry those paths or promise every
storage failure becomes recoverable. A sticky failure keeps its quota and can
block subsequent giant admission. The transient fake-retirement tests validate
the foreign wrapper algorithm, not recovery of quarantined native directories.

Three UniFFI close renames keep actual asynchronous retirement distinct from
AutoCloseable's synchronous foreign-handle disposal. No Cargo/lock/schema/library
contract-version change, new dependency, credential/provider call, platform UI
change, old-worktree cleanup or hardware action is included.
