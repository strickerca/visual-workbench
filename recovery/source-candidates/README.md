# Preserved source candidates

These source-only recovery packages preserve valuable unmerged work from retired
Design Workbench worktrees. They are intentionally outside active build roots.
They are not promoted runtime implementations or a passing product checkpoint.

Start from MANIFEST.json and the canonical implementation plan. Each file keeps
its source bytes/hash and provenance. Private receipts, original manifests with
local paths, binary artifacts and older generators remain in verified local
worktree archives. No private archive may be uploaded wholesale.

Priority: finish the unbuilt m4-picker Desktop repair and normal Paint sequence
under a fresh Windows resource owner. Do not replace current Main with the
separate diagnostics overlay. Diagnostics source is reviewed but its 20 written
tests are unrun. Phase 3 candidates are unbuilt/unrun: recover latest compositions,
review dependencies/limits, run focused checks, and integrate deliberate hunks.

For documents use SVG R3 and protocol/raster/Windows worker R2; restricted
redaction refuses unsupported content. For formats use ordinary composition,
not older resume sketches. transport/t3-stream-finish supersedes t3-stream;
formats/color admission precedes overlapping stream hunks. Phone-drawn region
authority and full software/hardware acceptance remain open.

binding generation, app controllers, Main/WorkbenchApp and central evidence.
Never execute old generators or wholesale-copy stale postimages over current
source. Keep original performance targets, privacy rules and pending gates.
