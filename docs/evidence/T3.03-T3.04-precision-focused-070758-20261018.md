## Coordinator correction 1: constructor call does not compile

`apps/android/src/main/kotlin/com/visualworkbench/android/editor/EditorController.kt:61`
currently calls:

```kotlin
val precision: PrecisionController = PrecisionController(core) {
    if (!disposing && !synchronizingPrecision) publish()
}
```

The actual constructor parameters are core, required `changed: () -> Unit`,
defaulted factory, then defaulted renderMatrix. Kotlin binds a trailing lambda to
renderMatrix; it does not fill the missing required changed argument.

A pinned-compiler probe against the real unchanged common class reproduces:

```text
error: no value passed for parameter 'changed'.
error: argument type mismatch: actual type is '() -> Unit',
but '(Camera, Point, Point, Int) -> Transform' was expected.
```

Minimal coordinator correction (corrected call-shape probe compiles):

```kotlin
val precision: PrecisionController = PrecisionController(core, changed = {
    if (!disposing && !synchronizingPrecision) publish()
})
```

## Coordinator correction 2: hover exit loses a held barrel timestamp

`apps/android/src/main/kotlin/com/visualworkbench/android/editor/CanvasSurface.kt:224`
unconditionally calls `buttons.reset()` on ACTION_HOVER_EXIT. A hover exit can
precede contact while the primary barrel remains held. Reset drops the helper's
physical press timestamp; the router clears hover and beginTool cancels the old
interaction, then DOWN can restart that physical hold as a new short press.

A focused host sequence uses the frozen actual helper and native-backed current
PrecisionController:

1. Hover with primary barrel pressed at 100 ms.
2. Execute the current hover-exit helper reset and router's hover(null) effect.
3. Execute beginTool's cancel/down order; primary is still held at 500 ms.
4. Release at 550 ms.

Expected: the 450 ms hold remains peek-only. Actual frozen sequence: a 50 ms
press is inferred, queuing a precision toggle. The expected-behavior assertion
fails. A paired sequence retaining R2's original pressedSince passes and queues
no toggle. These are 2 separate caller probes (1 failure / 1 pass), not included
in the 36 passing module cases.

Minimal correction: preserve the button helper's physical press timestamp across
hover-to-contact, particularly a HOVER_EXIT packet still carrying the held primary
button. R2's `buttons.accept(packet); router.accept(packet)` order retains it;
keep resets for actual cancellation, blocked admission and surface retirement.
Do not clear that timestamp solely because hover ends. The exact physical S Pen
packet sequence still requires local acceptance; the admitted synthetic sequence
already demonstrates the state-loss defect in the current hook.
