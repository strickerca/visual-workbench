## Goal

Prove the first-win image-edit loop end to end with the real API: crop-and-stitch, composite, and proof that nothing outside the mask changed.

## Steps

1. From OpenAI's official documentation (developers.openai.com: the image generation guide and the API reference), record the following with URLs and today's date:
   - the current image-edit endpoint, and the model IDs (as of 2026-09 the research found the gpt-image-2.5 family);
   - mask format; size constraints (side multiple, long-edge limit, minimum and maximum total pixels, allowed aspect range); quality settings;
   - pricing and rate limits;
   - any organization-verification requirement.
2. Key: Christian stores the key himself in Windows Credential Manager as a generic credential with the address `VisualWorkbench/openai` and the user name `openai` (his steps below). Your code only reads it (CredReadW through the windows crate, or a permissively licensed wrapper). Never ask for the key in this session. If it ever appears in the chat or in a file, tell Christian to revoke it at platform.openai.com and create a new one.
3. Cost guard: keep a running cost estimate from the documented prices; stop and ask Christian before the total passes $2.
4. Build a Rust CLI, `tools/ai-spike` (add to the workspace).
   - Inputs: an image path, a mask PNG or rectangle, a prompt, and a feather radius in pixels.
   - Implement §4.9.2 steps 1–8 exactly: bbox expanded 1.75× with a 64 px minimum margin; C grown to an allowed aspect ratio; S chosen to meet the side multiple, aspect range and minimum/maximum pixel count (small crops are upscaled); Lanczos3 resize; sRGB conversion; the request; resize back; feathered composite; source copy outside the crop; proof over dilate(M, feather + 1).
   - Outputs: composite PNG; proof JSON (changed_outside, hashes, ΔE2000 mean/max, SSIM inside the mask); timings (local processing vs model); cost estimate.
5. Test images: ask Christian for three of his own photos (one with a sign or visible text, one with an object that could be removed, one plain scene) in `fixtures-private/`, with location data removed; or use CC0-licensed photos and record their source URLs. Run five edits: change a region's color; remove an object; change the sign's text; one with a mask touching the image border; one with a mask under 100×100 px (to prove the minimum-pixel handling).
6. Verify changed_outside == 0 with a separate, independent diff script.
7. Write docs/evidence/T0.11.md with small preview images, numbers and costs, and note any API quirks. Run the secrets scan.

## Rules
